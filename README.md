# Multi-Tenant-Security

A modern, robust Multi-Tenant Security & Organization Management Platform.

## Features
- Multi-Tenant Isolation and Data Partitioning
- Role-Based Access Control (Admin, Manager, User)
- Admin Security Control Panel with Dynamic Navigation (Dashboard, Users, Campaigns, Security Events, Audit Logs)
- JWT Authentication & Secure Session Management
- Fast modern frontend built with Vite, React, and Tailwind CSS
- Secure backend API built with Express.js

## Project Structure
- `/backend`: Node.js & Express API server with database migrations and authentication
- `/frontend`: React + Vite web client with responsive dashboard layout
